Конфиденциальность

Сайт использует Google Analytics для статистики посещений. Google получает сведения о посещённых страницах и браузере, а также IP-адрес при подключении; сервис может использовать cookies. Как Google использует данные.

Гостевую книгу обслуживает HTML Comment Box. Имя и текст опубликованного комментария видны всем: не указывайте в них личные данные, которые не хотите раскрывать. При отправке виджет определяет публичный IP-адрес через ipify и передаёт его вместе с сообщением провайдеру. Конфиденциальность HTML Comment Box (PDF) · ipify.

Сайт размещён на GitHub Pages; при посещении GitHub также получает технические данные подключения. Конфиденциальность GitHub. Вопросы о сайте и опубликованных комментариях: mbox4s@gmail.com.

Privacy

This site uses Google Analytics to understand visits. Google receives information about pages visited and your browser, and your IP address when connecting; the service may use cookies. How Google uses information.

The guestbook is provided by HTML Comment Box. Your name and published comment are public: do not include personal details you do not want to share. When submitting, the widget looks up your public IP address through ipify and sends it to the provider with your message. HTML Comment Box privacy policy (PDF) · ipify.

The site is hosted on GitHub Pages; GitHub also receives technical connection data when you visit. GitHub privacy statement. Questions about this site or published comments: mbox4s@gmail.com.

פרטיות

האתר משתמש ב-Google Analytics לצורך סטטיסטיקת ביקורים. Google מקבלת מידע על הדפים שנצפו ועל הדפדפן, וכן את כתובת ה-IP בעת החיבור; השירות עשוי להשתמש בעוגיות. כיצד Google משתמשת במידע.

ספר האורחים מופעל באמצעות HTML Comment Box. השם והתגובה שפורסמה גלויים לכולם: אין לכלול פרטים אישיים שאינכם רוצים לחשוף. בעת השליחה, הרכיב מאתר את כתובת ה-IP הציבורית באמצעות ipify ושולח אותה לספק יחד עם ההודעה. מדיניות הפרטיות של HTML Comment Box (PDF) · ipify.

האתר מאוחסן ב-GitHub Pages; גם GitHub מקבלת נתוני חיבור טכניים בעת הביקור. מדיניות הפרטיות של GitHub. לשאלות על האתר או על תגובות שפורסמו: mbox4s@gmail.com.
